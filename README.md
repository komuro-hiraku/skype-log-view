# Skype Log Viewer

Skype のエクスポートログ (`messages.json`) をブラウザで閲覧する軽量 Web アプリケーションです。

## 機能

- `messages.json` のドラッグ＆ドロップまたはファイル選択で即時表示
- 会話一覧（最新順）・会話内フィルター検索
- チャットバブル形式のメッセージ表示（自分 / 相手 / システムメッセージ）
- **メッセージ内全文検索** — ハイライト表示、前後ナビゲーション、件数表示
- **ブックマーク** — メッセージ単位でトグル、`localStorage` に永続化、サイドバーからジャンプ
- 各種メッセージタイプ対応（テキスト、ファイル添付、通話、メンバー追加/削除 etc.）
- ファイルはすべてブラウザ内のみで処理（サーバーへの送信なし）

## 動作環境

- **OS**: Linux
- **ランタイム**: [Bun](https://bun.sh/) v1.0 以上

## セットアップ

### 1. Bun のインストール

```bash
curl -fsSL https://bun.sh/install | bash
```

インストール後、シェルを再起動するか以下を実行してパスを反映します。

```bash
source ~/.bashrc   # bash の場合
# または
source ~/.zshrc    # zsh の場合
```

バージョン確認:

```bash
bun --version
```

### 2. リポジトリのクローン

```bash
git clone https://github.com/komuro-hiraku/skype-log-view.git
cd skype-log-view
```

### 3. 依存パッケージのインストール

```bash
bun install
```

## 使い方

### サーバーの起動

```bash
bun start
```

ブラウザで <http://localhost:3000> を開いてください。

ポートを変更する場合:

```bash
PORT=8080 bun start
```

### ファイルの読み込み

1. Skype デスクトップアプリ → **設定** → **アカウントとプロフィール** → **Skype データをエクスポート**
2. ダウンロードした zip を展開
3. `messages.json` をブラウザ画面にドラッグ＆ドロップ（またはファイル選択ボタンをクリック）

### 検索

- ツールバーの検索ボックスにキーワードを入力
- **↓ / Enter**: 次の一致箇所へ
- **↑ / Shift+Enter**: 前の一致箇所へ
- **✕ / Esc**: 検索クリア

### ブックマーク

- メッセージにカーソルを当てると右下に 🏷️ アイコンが表示されます
- クリックでブックマーク登録（🔖）/ 解除
- サイドバーの **ブックマーク** タブからジャンプ可能
- ブックマークはブラウザの `localStorage` に保存され、再起動後も維持されます

## 開発

ファイルを変更すると自動でサーバーが再起動するウォッチモード:

```bash
bun dev
```

## Cloudflare Pages へのデプロイ

ビルドステップ不要です。静的ファイル (`index.html`, `style.css`, `app.js`) をそのままデプロイできます。

1. Cloudflare Pages の **新しいプロジェクト** を作成
2. Git リポジトリを接続
3. ビルド設定:
   - **ビルドコマンド**: (空欄)
   - **出力ディレクトリ**: `/` (ルート)
4. デプロイ

> Cloudflare Pages 上では `server.ts` は使用されません。ブラウザが直接静的ファイルを配信します。
